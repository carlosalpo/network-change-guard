# Project illustrations

Original conceptual artwork created for Carlos Alvarado’s Network Change Guard portfolio and repository with OpenAI image generation. These are visual metaphors for comparison and evidence review, not device screenshots or validation evidence. The tool does not deploy changes or execute rollback.

- `network-change-guard-cover-v1.png`: baseline/candidate comparison and inspection.
- `network-change-guard-detail-v1.png`: configuration-review workbench and evidence archive.

PNG, 1536 × 1024, transparent background.
